## <a name="english"></a> 🇬🇧 English

**Smart Budget Tracker** is a fast, comprehensive, client-side web application designed to help users take control of their personal finances. Built entirely with Vanilla web technologies, it calculates your remaining budget, analyzes your spending habits (Needs vs. Wants), and projects your savings potential—all while ensuring 100% data privacy.

### ✨ Key Features

- 💰 **Income & Expense Tracking**: Easily log transactions with custom categories and frequencies (weekly, monthly, yearly).
- ⚖️ **Budget Breakdown**: Automatically categorizes expenses into "Needs" and "Wants" following standard financial advice (50/30/20 rule).
- 🎯 **Savings Goals**: Track your progress towards multiple financial objectives with visual progress bars.
- 📈 **Interactive Projections**: Calculate how much your current remaining budget could generate in 1, 5, or any custom number of years.
- 🌍 **Bilingual Interface**: Instantly switch between English and French without reloading.
- 🔒 **100% Private**: No databases, no servers, no tracking. All data is securely stored in your browser's `localStorage`.
- 📤 **Export & Share**: Download your financial data as a CSV file (Excel-compatible) or share a quick text summary native to your device.

### 🛠️ Tech Stack

- **HTML5 & CSS3**: Pure, semantic HTML with a custom, highly responsive CSS design built from scratch (no external CSS framework).
- **Vanilla JavaScript**: All logic, translations, DOM manipulation, and state management handled via native JS.
- **Local Storage API**: Persistent client-side data storage.

## <a name="français"></a> 🇫🇷 Français

**Smart Budget Tracker** est une application web rapide et complète conçue pour vous aider à reprendre le contrôle de vos finances. Développée uniquement avec des technologies web standards, elle calcule votre reste à vivre, analyse vos habitudes de dépenses (Besoins vs Envies) et projette votre potentiel d'épargne, le tout en garantissant une confidentialité totale de vos données.

### ✨ Fonctionnalités Principales

- 💰 **Suivi des revenus & dépenses** : Ajoutez facilement des transactions avec des catégories personnalisées et des fréquences (hebdomadaire, mensuelle, annuelle).
- ⚖️ **Répartition du budget** : Catégorise automatiquement les dépenses en "Besoins" et "Envies" pour vous aider à y voir plus clair.
- 🎯 **Objectifs d'épargne** : Suivez votre progression vers de multiples objectifs financiers grâce à des barres de progression dynamiques.
- 📈 **Projections interactives** : Découvrez combien votre reste à vivre actuel pourrait générer dans 1, 5, ou n'importe quel nombre d'années.
- 🌍 **Interface bilingue** : Basculez instantanément entre le français et l'anglais sans recharger la page.
- 🔒 **100% Privé** : Aucune base de données, aucun serveur, aucun pistage. Toutes vos données sont stockées en toute sécurité dans le `localStorage` de votre navigateur.
- 📤 **Export & Partage** : Téléchargez vos données au format CSV (compatible Excel) ou partagez un résumé rapide directement depuis votre appareil.

### 🛠️ Technologies Utilisées

- **HTML5 & CSS3** : HTML sémantique pur avec un design CSS sur-mesure ultra-réactif (sans framework externe).
- **Vanilla JavaScript** : Toute la logique, les traductions, la manipulation du DOM et la gestion d'état sont codées en JS natif.
- **API Local Storage** : Stockage persistant des données côté client.
